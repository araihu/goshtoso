# templ components & JavaScript reference

Verbatim from templ.guide. templ v0.3.x.

## Component model

A component is markup+code compiled by `templ generate` into a Go function returning `templ.Component`:

```go
type Component interface {
	Render(ctx context.Context, w io.Writer) error
}
```

```templ
templ headerTemplate(name string) {
	<header data-testid="headerTemplate">
		<h1>{ name }</h1>
	</header>
}
```
Generated:
```go
func headerTemplate(name string) templ.Component { /* ... */ }
```

**Visibility** follows Go: uppercase first letter = exported, lowercase = private.

## Code-only components

Implement the interface directly with `templ.ComponentFunc`. **You are responsible for escaping** in code-only components.
```go
func button(text string) templ.Component {
	return templ.ComponentFunc(func(ctx context.Context, w io.Writer) error {
		_, err := io.WriteString(w, "<button>"+text+"</button>")
		return err
	})
}
```

## Method components

Attach a component to a type; call inline with struct initialization.
```templ
templ (d Data) Method() {
	<div>{ d.message }</div>
}
```

## View models

Keep a clean separation between data and presentation: define a struct (the view model) carrying everything the template needs, build it in the handler/service layer, then pass it to the component. Avoids putting business logic in templates.

## CSS

### Class & style attributes
```templ
<button class={ className }>{ text }</button>
<button class={ "button", className }>{ text }</button>
<button class={ "button", templ.KV("is-primary", isPrimary) }>{ text }</button>
<button class={ map[string]bool{"active": isActive, "disabled": isDisabled} }>x</button>
<button style={ style }>{ text }</button>
```

### `css` components (autogenerated unique class names)
```templ
css primaryClassName() {
	background-color: #ffffff;
	color: { red };
}
css loading(percent int) {
	width: { fmt.Sprintf("%d%%", percent) };
}
templ button(text string, isPrimary bool) {
	<button class={ templ.KV(primaryClassName(), isPrimary) }>{ text }</button>
}
```
Supported style value types: `string`, `templ.SafeCSS`, `map[string]string`, `templ.KeyValue[string,string]`, `templ.KeyValue[string,bool]`.

## JavaScript

### Plain script tags
```templ
templ body() {
	<script>
		function handleClick(event) { alert(event + ' clicked'); }
	</script>
	<button onclick="handleClick(this)">Click me</button>
}
```
`prettier`/`prettierd`/`npx` on PATH → templ formats `<script>` contents. Wrap shared scripts in `templ.OnceHandle().Once()` to emit once per response.

### Pass Go data to a JS event handler — `templ.JSFuncCall` (JSON-encoded, safe)
```templ
<button onclick={ templ.JSFuncCall("alert", data.Message) }>Show alert</button>
// → <button onclick="alert('Hello, from the JSFuncCall data')">Show alert</button>
```

### Pass the event object — `templ.JSExpression` (⚠ bypasses JSON encoding, XSS risk if untrusted)
```templ
<button onclick={ templ.JSFuncCall("clickHandler", templ.JSExpression("event"), "message from Go") }>Show event</button>
// → <button onclick="clickHandler(event, 'message from Go')">Show event</button>
```

### Call a client function with server data (emits a `<script>`)
```templ
@templ.JSFuncCall("functionToCall", data.Name, data.Age)
// → <script>functionToCall("John", 42);</script>
```
Invalid function names sanitize to `__templ_invalid_function_name`. Use `templ.JSUnsafeFuncCall` only for trusted, validated strings.

### Pass data in an HTML attribute (Alpine pattern) — `templ.JSONString`
```templ
<button id="alerter" alert-data={ templ.JSONString(data) }>Show alert</button>
<div x-data={ templ.JSONString(data) }>...</div>
```
Client: `JSON.parse(el.getAttribute('alert-data'))`.

### Pass data in a script element — `templ.JSONScript`
```templ
@templ.JSONScript("id", data)
// → <script id="id" type="application/json">{"msg":"..."}</script>
```
Client: `JSON.parse(document.getElementById('id').textContent)`.

### Interpolate Go data inside a `<script>` — `{{ value }}` (auto-escaped)
```templ
<script>
	const message = "Your message: {{ msg }}";  // inside string → raw escaped
	const obj     = {{ msg }};                   // outside string → JSON encoded
</script>
```

> templ recommends passing data via attribute or script tag over inline interpolation — separates data from code.

### `script` templates (typed JS functions)
```templ
script withParameters(a string, b string, c int) {
	console.log(a, b, c);
}
templ Button(text string) {
	<button onClick={ withParameters("test", text, 123) }>{ text }</button>
}
```

## Render once (`OnceHandle`)
```templ
var helloHandle = templ.NewOnceHandle()
templ hello(label, name string) {
	@helloHandle.Once() {
		<script>function hello(name){ alert('Hello, ' + name + '!'); }</script>
	}
	<div>...</div>
}
```
