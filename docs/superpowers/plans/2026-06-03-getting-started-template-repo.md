# Getting Started Template Repo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Getting Started immediately runnable by publishing a starter repo with app images and updating the docs page to show the live expected outcome first.

**Architecture:** Keep the Goshtoso docs site server-rendered. Add a small Getting Started preview model in the site, add/restore the generic table image cell API in the library, and make the external starter repo the complete copyable app. The docs page links to the starter repo and renders a same-page preview using the same table component patterns.

**Tech Stack:** Go 1.26+, templ v0.3.x, HTMX v2, Alpine.js v3, Tailwind CSS v4, Playwright E2E, GitHub CLI.

---


Expected: FAIL with `undefined: table.ImageCell`.

- [ ] **Step 2: Implement `ImageCell` and keep `UserCell`**

In `components/table/table.templ`, replace the `UserCell` helper block with:

```templ
// ImageCell renders an image cell with a round image, primary label, and detail text.
templ ImageCell(imageURL string, label string, detail string) {
	<div class="flex items-center gap-3">
		<img src={ imageURL } alt="" class="size-10 rounded-full object-cover"/>
		<div class="min-w-0">
			<div class="font-medium text-on-surface-strong dark:text-on-surface-dark-strong truncate">{ label }</div>
			<div class="text-sm text-on-surface-muted dark:text-on-surface-dark-muted truncate">{ detail }</div>
		</div>
	</div>
}

// UserCell renders a user cell with avatar, name, and email.
templ UserCell(avatarURL string, name string, email string) {
	@ImageCell(avatarURL, name, email)
}
```

- [ ] **Step 3: Generate templ output and verify**

Run:

```bash
templ generate
go run /tmp/goshtoso-imagecell-check.go
```

Expected: PASS.

- [ ] **Step 4: Commit**

```bash

git commit -m "feat(table): add generic image cell"
```
