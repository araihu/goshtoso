# Component API Normalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Normalize the known public component config fields to the canonical grammar in `docs/COMPONENT_API_NAMING.md`, accepting breaking API changes.

**Architecture:** Apply the migration in small, compile-checked batches. Rename source fields in `components/**/types.go` and `.templ` first, update site/demo/examples usages next, then regenerate templ and usage docs from the source of truth. Generated `*_templ.go` and `.claude/.agents` component references are outputs, never hand-edited.

**Tech Stack:** Go 1.26+, templ v0.3.x, HTMX, Alpine.js, Tailwind CSS, `go test`, `templ generate`, `go run ./scripts/skillgen`.

---

## File Structure

- `docs/COMPONENT_API_NAMING.md`: canonical naming guide already added.
- `components/*/types.go`: public config field definitions and helper methods.
- `components/*/*.templ`: component render source using renamed fields.
- `site/internal/pages/demo/components/*.templ`: API tables and examples for component docs.
- `site/internal/pages/demo/examples/*.templ`: example apps using renamed fields.
- `site/internal/pages/demo/examples/*_table.go`: table config usage in examples.
- `site/internal/server/*.go`: server-side component example configs.
- `components/**/*_test.go` and `site/tests/e2e/*.go`: focused compile/render/e2e checks where renamed fields affect behavior.
- `.claude/skills/using-goshtoso/components-reference.md`: generated by `go run ./scripts/skillgen`.
- `.agents/skills/using-goshtoso/components-reference.md`: generated by `go run ./scripts/skillgen`.

## Canonical Rename Map

Apply these known renames. Do not add deprecated aliases.

### Render Target Hooks

- `Class` -> `RootClass` when it styles the outer/root element.
- `Class` -> `NavClass` when it styles a semantic `<nav>`.
- `Class` -> `PanelClass` when it styles a drawer/modal/popup panel.
- `Class` -> `InputClass` when it styles a native input directly.
- `Attrs` -> `RootAttrs` when applied to the root rendered element.
- `Attrs` -> `InputAttrs` when applied to a native `<input>`, `<select>`, or `<textarea>`.
- `NavAttrs` stays `NavAttrs` only for semantic `<nav>` elements.
- `Step.Attrs` -> `StepAttrs` because it applies to each rendered step item.

### Text And Action Fields

- `badge.Config.Text` -> `Label`.
- `banner.Config.Text` -> `Description`.
- `banner.CTAConfig.Text` -> `ActionLabel`.
- `alert.LinkConfig.Text` -> `Label`.
- `alert.ActionConfig.PrimaryText` -> `PrimaryLabel`.
- `modal.Config.TriggerText` -> `TriggerLabel`.
- `modal.Config.PrimaryText` -> `PrimaryLabel`.
- `modal.Config.SecondaryText` -> `SecondaryLabel`.
- `tooltip.Config.Text` -> `Label`.
- `tooltip.Config.TriggerText` -> `TriggerLabel`.
- `tooltip.Config.TriggerContent` -> `Trigger`.
- `keyvalue.Config.AddLabel` -> `AddActionLabel`.
- `tagslist.Config.AddLabel` -> `AddActionLabel`.
- `triplet.Config.AddLabel` -> `AddActionLabel`.
- `navbar.Config.RightSlot` -> `Actions` with `ActionRight` where possible; if the API needs a direct slot, rename it to `RightActions`.

### Form Control Text And Attrs

- `checkbox.Config.Description` -> `HelperText`.
- `radio.Config.Description` -> `HelperText`.
- `schemaform.Field.Description` -> `HelperText` only if the field is rendered as form helper copy.
- `textinput.Config.Attrs` -> `InputAttrs`.
- `textarea.Config.Attrs` -> `InputAttrs`.
- `select.Config.Attrs` -> `InputAttrs`.
- `fileinput.Config.Attrs` -> `InputAttrs`.
- `toggle.Config.Attrs` -> `InputAttrs`.
- `radio.Config.Attrs` -> `InputAttrs`.
- Preserve `HelperText` on `textinput`, `textarea`, `select`, and `fileinput`.

### Transport And Reactivity

- `combobox.Config.HXMTEndpoint` -> `HTMXEndpoint` as a typo repair in the legacy API, unless this task also introduces a grouped `HTMX *HTMXConfig`.
- `pagination.Config.HTMXTarget` and `HTMXSwap` -> `HTMX *HTMXConfig` with fields `Target` and `Swap`.
- `table.Config.HTMXEndpoint` and `HTMXTarget` -> `HTMX *HTMXConfig` with fields `Endpoint` and `Target`.
- `select.Config.AlpineModel` and `AlpineBindDisabled` -> `Alpine *AlpineConfig` with fields `Model` and `BindDisabled`.
- `palette.Config.AlpineModel` -> `Alpine *AlpineConfig` with field `Model`.
